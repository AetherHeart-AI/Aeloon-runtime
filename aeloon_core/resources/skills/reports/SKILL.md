# 业务报表与报告

## 定义口径

先明确报告受众、报告周期、数据截止时间、业务范围、币种或单位，以及每个指标的定义。为关键指标记录来源、计算公式、筛选条件和负责人。不同来源存在冲突时不要擅自选择，应展示差异并说明处理方式。

## 构建可核验的数据链

1. 保留原始数据或来源引用，不直接覆盖。
2. 清洗日期、单位、空值、重复项和分类名称。
3. 将输入、计算和展示分离，避免手工复制计算结果。
4. 使用汇总、交叉核对或抽样复算验证关键数字。
5. 对异常值、估算值和缺失值作清晰标注，不用零值冒充未知值。

## 组织报告

- 开头给出报告周期、范围和数据状态。
- 管理层摘要优先呈现结论、变化原因、风险和建议行动。
- 表格适合精确查阅；图表适合展示趋势、构成、比较和关系。
- 图表标题应表达结论，并标注单位、时间范围、基准和来源。
- 对同比、环比、完成率等派生指标说明公式，并确保分母有效。

## 质量检查

核对总计与明细、跨表数字、正负号、百分比、四舍五入、时间范围和单位。检查筛选条件是否意外遗漏数据，结论是否由数据支持，建议是否区分事实与判断。交付时附上数据更新时间、关键口径、限制条件和待确认项。
