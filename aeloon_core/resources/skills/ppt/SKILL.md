# PPT 演示文稿

## 定义演示策略

明确受众、演示时长、场景、期望行动和一句话核心结论。优先形成完整叙事，再拆分页面；不要把文档段落直接搬到幻灯片中。

## 组织叙事

根据任务选择合适结构，例如：

- 决策汇报：背景 → 问题 → 证据 → 方案 → 权衡 → 建议 → 下一步。
- 项目进展：目标 → 当前状态 → 已完成 → 风险 → 需要支持 → 计划。
- 培训课件：学习目标 → 概念 → 示例 → 练习 → 总结。
- 销售或路演：受众痛点 → 价值主张 → 方案 → 证据 → 差异化 → 行动邀请。

每页表达一个主要观点，使用结论型标题。删除不能推动叙事的页面和内容。

## 设计页面

- 用图表、流程、时间线、对比和关键数字承载关系，避免大段文字。
- 控制文本密度，保持字号、留白、对齐、配色和图形风格一致。
- 图表注明指标、单位、时间范围和来源；不使用装饰性图表掩盖数据不足。
- 需要讲解的细节放入演讲者备注，不挤占页面主体。
- 用户提供模板或品牌规范时优先遵循；没有模板时采用克制、专业且高对比度的视觉体系。

## 交付前检查

逐页检查标题是否能串成完整故事，数字和结论是否一致，图表是否可读，引用是否可追溯，页面是否存在溢出、遮挡或低对比度。条件允许时渲染全部页面进行视觉检查，并修复后再次验证。
